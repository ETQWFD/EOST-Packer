# EOST Packer

在安卓手机上一键打包、签名、加固安卓应用的工具。

- 内置 aapt2 / aapt / d8 / zipalign / apksigner
- 支持 32 位 / 64 位 / x86 设备
- Android 15 Material You 风格界面
- 首页公告（从官网后台同步）
- 打包设置、权限管理、依赖补全、AI 帮助
- V1 / V2 签名，自定义签名文件
- EOST 自动加固
- 明亮 / 暗黑 / 跟随设备主题
- 简体中文 / English
- 开发者：龙腾OS

## 构建

```bash
bash build.sh
```

产物：`build/EOST-Packer.apk`
